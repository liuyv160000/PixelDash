## 三、关键约定（搭场景时必须遵守）

| 约定 | 原因 |
|---|---|
| 玩家节点名必须是 **`player`** | `EnemyControllerBase`/子弹等用 `GameObject.Find("player")` 与其碰撞判定 |
| 平台父节点名 **`plat_ver`**、子节点名 **`plat_line`** | `PlayerController` 的落地判定与重力反转前置条件依赖这两个名称 |
| 世界坐标：**1 unit = 1 px**，相机正交 size = **360** | 全部速度/坐标沿用源项目像素值 |
| `Physics2D.gravity` 由 `ExManager.Awake` 设为 **`(0, -320)`** | 与源项目一致；玩家 `gravityScale = 2.5` |
| 输入：键盘 `W/↑`(Up)、`S/↓`(Down)、`Space/J`(Attack)、`A/D`(转向) | 走 `UnifieldInputManager`，无它时 `PlayerController` 自动回退直读键盘 |
| 脚本**不会覆盖**你在 Inspector 指定的 Sprite | `PlaceholderSprite.EnsureRenderer` 仅在 sprite 为空时补占位 |

## 四、源项目 → 本工程的映射说明

| 源实现 | 本工程 | 原因 |
|---|---|---|
| 14 个独立 sound manager | 1 个 `AudioManager` + 事件订阅 | 逻辑集中、便于接真实音源 |
| `background_announcer` 轮询技能球节点 | 监听 `BULLET_POWERUP_COLLECTED` | 事件驱动更可靠 |
| `ex_manager` + `ex_move_ctrl` 移动根节点 | 未复刻（各系统独立移动） | 源行为冗余/疑似 bug，等价效果已实现 |
| `load_scene_1` 过渡场景 | 直接切目标场景 | 过渡可由后续淡入淡出替代 |
| 源 PNG 由 Cocos 图集管理 | 独立 PNG → Unity 自动图集/Sprite Atlas（可选） | 简化导入 |
