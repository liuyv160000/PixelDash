## 三、关键实现点

- **玩家**：5 状态 FSM、重力反转（`gravity_reverse` 驱动输入映射翻转）、固定 X（`Mathf.Lerp` 回正）、无敌 1s、碰撞落地判定 `plat_ver/plat_line`。
- **物理换算**：Unity 采用**像素级世界坐标**（1 unit = 1 px，`Physics2D.gravity = (0,-320)`，相机正交 size = 360）。源项目 `jump_force=30` 为 Cocos 引擎单位，换算为等效手感值 **450**（跳跃高 ≈126px，与源项目一致）；`quick_down_force` 90→900。
- **敌人**：5 类（normal_one 5 状态 / circle_saw 无状态不可击杀 / laser 2 状态 / tracking_missile 4 状态 / warning_zone 渐隐）。两关卡**完整时间表**已内置为预设（`ApplyPreset(0|1)`）：
  - fresh_hand：电锯 **0 个**、normal_one `[76]`、激光 `[58,58]`、追踪导弹 **18 点**
  - ex_scene_1：电锯 **13 点**、normal_one **12 点**、激光 **11 点**、追踪导弹 **46 点**
- **道具**：金币/3 类技能球/补给箱 + 3 类生成器，两关卡时间表已写入场景。
- **美术**：全部用程序化占位色块（`PlaceholderSprite`，按目标世界尺寸反推 PPU，不与 Collider 冲突）。

## 六、如何运行

1. 用 Unity Hub 打开 `E:\Unity\Unity project\PixelDash`（编辑器 2022.3.62f3c1）。
2. 打开 `Assets/Scenes/FreshHand.unity` → 按 **Play** → 按任意键开始（90 秒倒计时）。
3. 操作：`W/↑` 跳跃、`S/↓` 快速下落 / 线平台上翻转、`A/D` 转向。
4. 关卡流程：倒计时结束 → `VictoryScene`（可进第二关）；血量归零 → `FailScene`（重玩）。
5. 需要重建场景：菜单 **PixelDash → ① 构建全部场景**。
