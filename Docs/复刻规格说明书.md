> 源项目：`E:\Cocos project\Test2`（Cocos Creator 3.8.8, TypeScript）

> 复刻范围：`fresh_hand_scene.scene`（新手关） + `ex_scene_1.scene`（进阶关）两条会跳转的关卡完整链路。

## 一、源项目架构总览

三横切机制 + 六大系统：

- **事件总线**（`game_event_bus`）：5 管道 —— `player` / `enemy` / `bullet` / `collection` / `other`
- **FSM**（`fms/FMS`）：通用状态机，`registerState(name, state)` + `changeState(name)`
- **Timer**：可重置/暂停/续跑的计时器（`set_duration / start / stop / reset / reStart / check_if_end / get_elapsedTime`）
- **对象池**：敌人/子弹/技能球均由 maker 池化管理（min≈3~5，动态伸缩）

六大系统：玩家、敌人、子弹、道具、HUD、音频（音频第一版占位，9 音效通道不做）。

**关卡跳转链**：`editing_scene`(主界面) → `ex_choosing_scene`(选关) → `fresh_hand_scene` 或 `bullet_ex_choosing` → `ex_scene_1`；胜利 → `victory_scene`，死亡 → `fail_scene`。
**本工程只做 `fresh_hand_scene` 与 `ex_scene_1` 两个关卡场景**，带一个可直接 Play 的启动入口。

## 三、玩家系统

### 3.1 物理（RigidBody2D）
- 类型 dynamic、`gravityScale = 2.5`、`fixedRotation = true`
- 移动控制量：`jump_force = 30`、`quick_down_force = 90`、`gravity_reverse = 1`（1 向下为正重力 / -1 反转）
- 跳跃 = 沿重力反向给冲量 `(0, gravity_reverse * jump_force)`；快速下落 = `(0, -gravity_reverse * quick_down_force)`

### 3.2 状态机（5 状态）
| 状态 | 进入行为 | 更新 | 退出/转换 |
|---|---|---|---|
| `idle` | 播 idle 动画 | — | 输入 Jump → `jump` |
| `jump` | Jump() 给冲量；ifAir=true, ifGround=false | 当 y 速度相对重力开始反向（下落）→ `air` | — |
| `air` | ifAir=true, ifGround=false | — | 落地碰撞 → Land() → `idle` |
| `reversing` | 记 log_y；set_y_speed(-contentSize.y*gravity_reverse*0.31)；禁 collider；scale.y 翻转 | 位移过半身 → `air` | exit 恢复 collider、y_speed=0、reverse_the_gravity() |
| `dead` | — | 0.5 秒后 `loadScene("fail_scene")` | — |

### 3.3 输入与核心逻辑（`PlayerController`）
- `health=100`、`faceDir=1(朝右)/-1`、`invincibleDuration=1s`
- **统一输入**：键盘（W/↑=UP, S/↓=DOWN, A/D=左右）+ 触摸虚拟按钮（up/down）
- **输入→动作映射**（取决于 `gravity_reverse`）：
  - 重力正常(1)：UP→Jump；DOWN→在地面 Reverse()，在空中 quickDown()
  - 重力反转(-1)：UP→在地面 Reverse()，在空中 quickDown()；DOWN→Jump
  - 左右(A/D)：仅更新 faceDir
- `fixed_x_posittion()`：每帧 `lerp(node.x → sta_position.x, 0.1)` 固定 X 并平滑回正（玩家固定 X，只做 Y 轴）
- `Reverse()` 前置条件：`on_line && ifGround && if_can_reverse && !ifAir`（站在**线平台**上才允许反转）
- 落地判定：碰撞父节点为 `plat_ver` 的平台；若碰撞体带 `plat_line` 组件 → `on_line=true, if_can_reverse=true`，否则 false；然后 Land()
- 受伤 `get_hurted(damage)`：无敌时 return；否则重置/启动 1s 无敌、health-=damage、播 `invincle_hurt`、emit HURT；health≤0 → die()
- `apply_searchlight_debuff(duration, slowRate=0.5)`：减速 debuff（探照灯用），到期恢复
- `end_out_completed()`：emit game_end + 1s 后销毁（关卡胜利时调用）
- 暂停/恢复：`Pause()/Resume()` 控制 `is_paused`

## 四、敌人系统

### 4.1 生成管理器 `scene_enemy_manager`（挂 enemy_poster，计时器总长 90s）

按**时间表**在 enemy_poster 锚点生成，生成时把场景序列化参数注入敌人。5 类敌人、5 张时间表。

### 4.2 敌人基类 `enemy_controler_base`
- `enemy_hp=100`、`move_speed=100`、`move_dir(Vec2)`
- `onLoad`: player = node.parent.getChildByName("player")
- `update`: `move_by_speed` = 位置 += move_dir * move_speed * dt
- `get_hurted(damage)`: hp-=damage → die_check()
- `die_check()`: hp≤0 → emit enemy-killed + 0.5s 后销毁

### 4.3 各类敌人行为

**normal_one（普通飞行敌人，5 状态 FSM）**
- 状态：`on_in` → `idle` → `run_away`（state_timer 驱动，state_times=[1,10] 循环）；`atk`（攻击时切）；`dead`
- `patrol_dir`(1/-1)：move_dir 每 `loop_time = 261.5/move_speed` 反转一次（上下巡逻，height=523/2）
- `attack()`：敌人子弹发射点 y 落在 `[player.y, player.y+26]` 区间内、且攻击冷却(0.5s)到 → 发射 normal_attack_bullet（speed/damage 由 manager 传入）→ 切 `atk`，0.22s 后回 idle
- 入场保护 1.5s（protected_timer 内 collider 禁用），on_in 结束启用
- 碰玩家 → 玩家受伤 + 自身 dead + 回收
- 默认 move_speed=400

**circle_saw（电锯，无状态）**
- `move_dir=(-1,0)`，从 (800,-37.175) 向左直线移动，rotate 360°/s
- 碰玩家 get_hurted(damage)；出界(x<-800 或 >1380)回收
- 注意：`get_hurted` 是空实现（`enemy_hp -= 0`）—— 电锯**无法被玩家子弹杀死**（源项目行为）

**laser（激光，2 状态 FSM）**
- 状态 `warning`（预警）→ `attack`（攻击）
- 本体不动(move_speed=0)，在 manager 锚点 `-1150` 处生成
- `life_timer = atk_time`（0.3/0.5s），到期回收
- 碰玩家 get_hurted(damage)

**box_warning_zone（警戒区）**
- `warning_duration`（=set_warning_count=1s），按剩余时间渐隐（opacity=255*ratio），到期回收
- 在激光时间点 **提前 1s** 生成（manager 内部处理）

**tracking_missile（追踪导弹，4 状态 FSM）**
- 状态：`on_in`(2s) → `aiming`(1s) → `atk`(3s) → `dead`
- `on_in`: move_speed=400, move_dir=(-1,0) 向左入场
- `aiming`: `aiming()` 朝玩家方向（计算 dir + 旋转朝向）
- `atk`: 速度重置为 atk_start_speed(900)，每帧加速 accel=2200 直到 atk_max_speed
- 碰玩家 → 受伤 + dead + 回收（collider 变 sensor 防重复）
- 自然飞完(state_index==3) → dead + 回收
- 入场保护 1.5s

## 八、关卡流程（`ex_manager`）

- `total_time = 90`、`victory_scene_name="victory_scene"`、`victory_delay=0.6`、`use_new_enemy_manager=false`
- 启动：`start()` → 初始化输入监听 + `all_pause()`（暂停玩家/背景/道具/敌人/计时器/移动/字幕/音乐，等待开始）
- 任意键/触摸 → `startGame()` → 清空提示文本 + `set_up()` 恢复所有子系统
- `update()`：`timer.check_if_end()` → `end_game()`（player 无敌 + end_out_completed，0.6s 后切 victory_scene）
- 死亡在 Deadstate：0.5s 后 `loadScene("fail_scene")`
- 子系统 Pause/Resume 接口：玩家、背景、collection_poster(active)、music、scene_enemy_manager、timer、move_ctrl、start_tips、all_tips_ctrl、near_site_move

## 九、相机与背景

### 相机（`camera_controller`，挂 Camera 节点）
- **死区跟随**：dead_zone 碰撞箱定义死区；玩家在死区内不移动相机；超出则按 `minFollowSpeed=10`×`followSpeedMultiplier`（实际跟随用 4，ex_manager 引用用 2）平滑追到玩家
- 玩家速度同步（isSyncingVelocity）：追上后同速移动
- **重力反转检测**：反转时相机短时同步（0.1s）
- **受伤抖动**：`trigger_shake(12, 0.25, 35)`（player_hurt 事件触发）

### 背景（`background_controler`，speed=50 场景值，代码默认 2400）
- 3 张 city 图循环滚动：以中间图为基准整体 -X 移动，最左图超出半幅宽度移到最后
- `near_site` 前景（大楼/广告牌）由 `near_site_move`（move_speed=8/10, move_direction=-1）独立向左移动

## 十二、复刻范围与取舍

**完整复刻**：两关卡场景结构、玩家 5 状态 FSM + 重力反转 + 固定 X、4 类敌人状态机 + 时间表、2 类子弹、4 类道具 + 生成器、关卡流程 ex_manager、相机死区跟随 + 抖动、背景循环滚动 + 前景、HUD（倒计时/血条/公告/教学文案）、启动→胜利/失败跳转。

**第一版占位/简化**：
1. 音频（9 音效通道）→ 占位，不接真实音源
2. DaoSkill（刀，废案）→ 不实现
3. 美术资源 → 用占位色块/简形（源 PNG 未迁移；跑通逻辑优先）
4. 触摸虚拟按钮 → 键盘为主，Unity 旧 Input Manager（与源项目一致）
5. enemy_poster/collection_poster 的 prefab 引用 → 用程序化生成 sprite 占位
